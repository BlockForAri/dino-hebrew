# DinoHebrew 🦕

Fun Hebrew language learning web app for kids with dinosaurs, games, and rewards.

## Features
- 9 lessons (Animals, Colors, Numbers, Family, Greetings, Food, Body, Clothes, Actions)
- Games: Quiz, Match, Memory, Scramble, Listen & Choose
- Dual-language speech (Hebrew + English)
- Dinosaur collection rewards
- Progressive Web App (installable on Android, works offline)

## How to use
1. Open `dino-hebrew-web.html` in Chrome
2. On Android: Menu → Add to Home screen / Install app

## Note
Dinosaur images are in the `imagine_images/` folder. Download them from the conversation artifacts or generate your own and place them there for full visuals.

Made as a free open prototype.
